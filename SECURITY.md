# Безопасность

Не публикуйте уязвимости, токены ботов или персональные данные покупателей в открытых Issues.

Для приватного сообщения об уязвимости используйте GitHub Private Vulnerability Reporting в разделе **Security → Advisories → Report a vulnerability**. Владельцу репозитория следует включить эту возможность после публикации.

Если токен случайно попал в коммит, одного удаления строки недостаточно: немедленно отзовите токен в BotFather или панели MAX, выпустите новый и затем очистите историю Git.
